# claude-hooks

Hooks for [Claude Code](https://code.claude.com).

A hook is a small script that Claude Code runs at a set point, for example before each command.

| Hook | What it does |
|---|---|
| [quiet-noisy](quiet-noisy/) | Cuts long install, build and test output down to errors, failures and the final summary. This saves tokens. |

Each folder has its own README with install steps.
